# Laravel Test Project

A Laravel project for learning and testing Laravel features.

## Tech Stack
- PHP / Laravel
- MySQL
- Blade Templates

## Features
- Laravel routing
- Eloquent ORM
- Blade templating
- Middleware
- Authentication

## Requirements
- PHP >= 8.0
- Composer
- MySQL

## Setup
```bash
git clone https://github.com/GalihAlifyAlmas/test-laravel
cd test-laravel
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
